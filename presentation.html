01 · PROJECT BRIEF

Compliance-first onboarding

A Flutter mobile screen that verifies LSA records before submission and protects uncertain data through deterministic fail-closed behavior.

Core objective

Make lineage verification visible, traceable, and safe at the point of entry.

Design direction

Login/signup-inspired gradient, rounded card, soft fields, and a clear primary action.

03 · ARCHITECTURE

Small, explicit code boundaries

App shell

MyApp owns theme, title, and production-safe banner configuration.

Screen boundary

LsaVerificationScreen is the public integration surface and accepts an injectable HTTP client/endpoint.

State boundary

The private stateful form owns controllers, status, timers, and lifecycle cleanup.

Network boundary

One submit path builds the payload, applies mandatory headers, validates the response, and maps failures to quarantine.

“Byt” standard: boundaries are kept small, behavior is explicit, and dependencies are injected where external behavior must be tested.

06 · SECURITY

Fail-closed by default

ConditionAction
Empty predecessorThrow lineage failure, quarantine immediately, never call API
Timeout / HTTP 500Purge volatile fields, lock button, quarantine
Invalid JSON / null statusDo not infer success; apply same quarantine path

Only a successful HTTP response with a non-null status can transition the UI to Success.

7
07 · DATA LINEAGE

Orphan data never leaves the device

The predecessor ID is the gatekeeper for lineage. Validation occurs before form submission and before the HTTP client is invoked.

if (predecessor.trim().isEmpty) {
  quarantine();
  return; // no network call
}

After an uncertain response, all volatile controllers are cleared and the submission control remains disabled.

8
08 · OBSERVABILITY

Friction tracking without blocking flow

Focusing the consent field starts a five-second timer. Typing or submitting cancels it. Hesitation emits a structured UTC event:

[UI_FRICTION_LOG] Timestamp: <UTC> | Field: parent_consent_code | Hesitation Duration: 5.0s

The timer is canceled during disposal to avoid lifecycle leaks.
